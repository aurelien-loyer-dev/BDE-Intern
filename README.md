# BDE-Intern

Application React/Vite pour le site interne du BDE Epitech Réunion.

## Démarrage

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` lance le serveur de développement.
- `npm run build` génère la version de production.
- `npm run preview` prévisualise le build localement.

## Notes

- L&apos;authentification et la whitelist sont simulées côté frontend pour l&apos;instant.
- Pour restreindre les connexions localement, définissez `VITE_ALLOWED_EMAILS` avec une liste d&apos;emails séparés par des virgules.
- Les appels Supabase restent à brancher plus tard, comme indiqué dans le code.
